Каждый лендинг теперь находится в своей отдельной папке, является самостоятельным локальным репозиторием Git и будет загружаться в свой собственный отдельный проект на вашем аккаунте GitHub. Что вам нужно сделать на GitHub:
Поскольку на GitHub у вас сейчас создан только один репозиторий (Lending-Iryna), вам нужно создать еще 3 пустых репозитория под остальные лендинги:

Зайдите на свой аккаунт на сайте GitHub и нажмите кнопку New (или Create repository).
Создайте три репозитория со следующими названиями (точно, как указано ниже):
Lending-Lipolysisweek
Lending-Joints
Lending-Dermatitis
При создании оставьте галочки "Add a README file" выключенными (репозитории должны быть пустыми).
Как загрузить каждый лендинг на GitHub:
Я уже сделал все коммиты локально и привязал их к нужным ссылкам на GitHub. Чтобы загрузить любой из лендингов:

Откройте терминал в VS Code.
Перейдите в папку нужного лендинга с помощью команды cd (или просто выберите нужную папку как рабочую область в VS Code).
Запустите команду отправки:
bash
git push -u origin main
Если Git попросит войти на GitHub в браузере — войдите. Файлы отправятся в соответствующий репозиторий.
Как настроить доступ для других людей:
Для любого репозитория на GitHub (например, Lending-Lipolysisweek) вы можете дать доступ разработчикам или заказчикам:

Зайдите в этот репозиторий на сайте GitHub.
Перейдите во вкладку Settings (Настройки) сверху.
В левом меню выберите Collaborators (Соавторы).
Нажмите кнопку Add people (Добавить людей) и введите их email или никнеймы на GitHub, чтобы отправить приглашение с доступом к коду.
